# Lip-Sync & Speech-to-Text Computer Vision Project

## Creator / Dev
**tubakhxn**

## What is this project?
This is a real-time, terminal-based Python application that performs:
- Lip-sync detection using computer vision (OpenCV)
- Speech-to-text transcription using Whisper (offline)
- No MediaPipe, no GUI, runs only in the terminal
- Modular architecture for easy extension
- Auto-installs all dependencies if missing

## Tech Stack
- Python 3.11+
- OpenCV (face/mouth detection)
- numpy
- torch
- transformers (Whisper)
- sounddevice
- scipy

## How to Fork
1. Click the "Fork" button at the top right of this repository on GitHub.
2. Choose your GitHub account as the destination.
3. Clone your forked repo:
   ```sh
   git clone https://github.com/<your-username>/lip-sync.git
   ```
4. Install Python 3.11+ and run the project from the terminal:
   ```sh
   cd lip-sync
   python main.py
   ```
